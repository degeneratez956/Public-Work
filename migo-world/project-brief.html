Payment Processing — Replacing Square
The Problem with Square
$1,200+ in fees

Online Checkout
Stripe
2.9% + $0.30 per transaction · $0/month

Youth Event Protection

  • Photo / video release consent
  • Emergency contact collection
  • Age verification — confirms registrant is parent/guardian

Security

  • SSL certificate (HTTPS) — required by Stripe
  • Custom domain email (booking@migoworldent.com)
  • 2-factor authentication on all accounts
  • CAPTCHA on all public forms
  • Weekly automated backups
